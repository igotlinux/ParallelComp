Built for Systems & Compiler Engineers

Traditional benchmarks only measure wall-clock latency. KernelGuard tests mathematical correctness, hardware memory safety, and compiler code generation.

📐

~106-bit Double-Double Oracle

Uses Knuth's 2Sum and Dekker's 2Prod transformations to create an in-process, zero-dependency reference with ~106 bits of precision—an exact oracle for float32 operations.

🛡️

Guard-Page Memory Envelopes

Wraps allocations in virtual memory PROT_NONE guard pages and 64-byte canaries. Catches off-by-one SIMD buffer overruns instantly without crashing the runner.

🔍

Optimization Remarks & Disassembly

Parses GCC and Clang vectorization records, checks disassembly opcodes, and flags regressions when loops de-vectorize due to refactors.

⚡

NVIDIA CUDA & PTX Inspection

Compiles CUDA to PTX assembly and parses instruction histograms. Confirms FMA utilization, memory spaces, and launch boundaries across toolchains.

🎯

Delta Debugging Minimizer

When a test fails, Zeller's ddmin algorithm automatically shrinks the failing array into a 1-minimal test case and outputs a zero-dependency repro.cpp.

🔒

Committed Lockfile Regression Gates

Tracks vectorization state and instruction counts in kernelguard_lock.json. Rejects PRs that inflate instruction counts by more than 2%.

Drop into your GitHub Actions in 30 Seconds

KernelGuard runs as a standard GitHub Action. Simply add it to your .github/workflows/ci.yml:

name: "Kernel Verification"
on: [pull_request]

jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run KernelGuard Verification Matrix
        uses: igotlinux/kernal-guard@v1
        with:
          profile: 'quick'
          backend: 'cpu'
          fail-on-regression: true
